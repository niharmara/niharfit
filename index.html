Setup
1

Create a Google Sheet

Go to sheets.new and create a new spreadsheet. Name it NiharFit. Copy the Sheet ID from the URL — it's the long string between /d/ and /edit.

2

Create a Service Account

In Google Cloud Console → IAM & Admin → Service Accounts → Create. Name it niharfit. Skip optional steps. Then click the account → Keys tab → Add Key → Create new key → JSON. Download the file.

3

Share your Sheet with the Service Account

In your NiharFit Google Sheet, click Share and add the service account email (shown below after pasting the JSON) as an Editor.

4
