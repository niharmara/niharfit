Setup
1

Create a Google Sheet

Go to sheets.new and create a new spreadsheet. Name it NiharFit. Copy the Sheet ID from the URL — it's the long string between /d/ and /edit.

2

Get a Google API Key

Go to Google Cloud Console → Create credentials → API Key. Enable the Google Sheets API. Restrict the key to Sheets API + this URL.

3

Share your Sheet

In Google Sheets, click Share → change to "Anyone with the link can edit". This lets the app write your workout data.

4

Program Start Date

When did you start the current ULA v3 cycle? The app uses this to know which day you're on.

5

Import Historical Data

Upload your Spotter CSV export to pre-load your strength baselines and history.
